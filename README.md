\# Nassoro Product Alerts



Nassoro Product Alerts is a product-alert project designed to help businesses monitor important product information, including low stock, products approaching expiry, and supplier price changes.



\## Current Project Structure



\- `nassoro-alert-website/` — frontend website, CSS, JavaScript, images, icons, and PWA-related files.

\- `ProductAlert\_System/` — reserved for additional system components.



\## Current Status



The repository currently contains the website frontend. Backend services, database integration, authentication, and alert-processing features should be documented as they are implemented.



\## Technologies



\- HTML

\- CSS

\- JavaScript



\## Getting Started



Open `nassoro-alert-website/index.html` in a browser to preview the frontend.



\## Security



Do not commit `.env` files, database passwords, API keys, or other secrets.
