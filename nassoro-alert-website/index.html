What is Nassoro Alert?

Nassoro Alert is a smart system designed to monitor products and provide alerts about stock, expiry and supplier price changes.

Can I use Nassoro Alert on my phone?

Yes. Nassoro Alert is designed with mobile users in mind and the website can also be installed as a Progressive Web App.

Does the system monitor expiry dates?

Yes. One of the core features is expiry monitoring and alerts for products approaching expiry.

Will there be a desktop version?

Yes. Desktop and laptop access is part of the future development roadmap.
